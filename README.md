# Thirsty for Knowledge

A minimalist blog platform for publishing research-driven, thoughtful writing.

## Purpose

A quiet, ad-free space for curious minds - where readers can explore in-depth articles and directly influence what gets written next by requesting and voting on topics.

## Core Features

- **Posts** - Admin-authored, research-based articles written with a rich text editor
- **Engagement** - Like, comment (with replies), and share on posts
- **Topic Requests** - Readers suggest topics and upvote/downvote existing requests
- **Auth** - Google social login with role-based access (admin/user)
- **Admin tools** - Full post management (create, edit, delete, draft/publish)

## Tech Stack

**Frontend** - Next.js (App Router), Tailwind CSS, Framer Motion, Tiptap, Lottie

**Backend** - Express 5, MongoDB (Mongoose), Better Auth

**Other** - imgBB (image hosting), Vercel + Render (deployment)
